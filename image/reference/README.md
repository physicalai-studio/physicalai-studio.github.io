# 참조 이미지 (Reference — 커밋하지 않음)

여기에는 **제3자 저작물인 참고 이미지**를 둔다. 형태·분위기를 참고하기 위한 자료이며
**저장소에 커밋하지 않는다** (`.gitignore` 로 제외). 이 저장소는 공개이므로 남의 저작물을
올리면 저작권 침해가 된다.

## 규칙

- 여기 있는 이미지를 **사이트에 그대로 쓰지 않는다.** 어법만 참고해 `scripts/` 로 다시 계산한다.
- 참고해서 만든 결과물은 `image/concept/` 에 쌓이며 그쪽은 커밋된다(전부 자체 생성물).
- 출처를 아는 경우 파일명이나 이 문서에 남겨 두면 나중에 판단이 쉽다.
