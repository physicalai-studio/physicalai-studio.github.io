# 홈페이지 콘텐츠 사업 전환 전략

## 목표

기술 포트폴리오를 넓게 전시하는 홈페이지에서, 고객이 작은 범위로 발주하고 결과를 판단할 수 있는
1인 전문 스튜디오 홈페이지로 전환한다.

## 메시지 위계

1. **주력 상품** — 제작 전 검증, 재사용 가능한 시뮬레이션 테스트베드
2. **확장 상품** — 가상 시운전, 실기 정합
3. **연구 확장** — 강화학습·모방학습, Synthetic Data, Physical AI 평가 환경

확장 역량을 삭제하지 않는다. 다만 첫 화면과 홈의 상품 목록에서는 주력 상품이 먼저 이해되게 하고,
연구 확장은 고객의 정책·데이터·평가 기준이 준비된 경우에만 범위를 합의한다고 명시한다.

## 전환 원칙

- 첫 화면은 고객, 작업, 산출물을 한 문장 안에서 설명한다.
- 사례는 기술 이름보다 지원한 의사결정과 인계한 결과를 먼저 보여준다.
- 1인 기업임을 숨기지 않고 창업자가 직접 수행한다는 책임 구조로 바꾼다.
- 문의 전에 필요한 자료, 회신 기준, 진행 순서, 보안 원칙을 공개한다.
- 확인되지 않은 기간, 비용 절감액, 고객사 정보는 만들지 않는다.
- 브랜드·도메인 확정 전에는 임시 이메일을 영구적인 신뢰 장치처럼 포장하지 않는다.

## 적용 순서

1. 히어로와 검색 설명을 구체화한다.
2. 서비스를 주력·확장·연구 확장으로 재분류한다.
3. 기술 페이지에서 검증된 실무 스택과 연구 검토 항목을 분리한다.
4. 대표 사례에 의사결정·인계물·공개 범위를 추가한다.
5. About에 founder-led 운영 원칙과 수행 경계를 공개한다.
6. Contact의 준비 중 문구를 제거하고 실제 문의 프로토콜을 제공한다.
