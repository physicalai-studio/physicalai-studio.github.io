# 타이포그래피 원칙 (Typography)

> 상위 문서: [디자인_컨셉.md](디자인_컨셉.md) §6 — 이 문서는 그 원칙을 **실제 값과 컴포넌트**로 옮긴 것이다.
> 값의 정의는 [`src/styles/tokens.css`](../src/styles/tokens.css), 적용은 [`SectionHeading`](../src/components/section/SectionHeading.tsx) 과 [`Section`](../src/components/section/Section.tsx) 이 담당한다.
>
> 최종 갱신: 2026-08-13

---

## 1. 원칙 세 줄

1. **크기는 토큰으로만 정한다.** 컴포넌트가 임의의 `text-[52px]` 를 쓰지 않는다.
2. **한 페이지에 `h1` 은 하나.** 그 아래는 전부 `h2` 이하로 내려간다.
3. **여백은 리듬이다.** 섹션 사이 간격이 페이지마다 다르면 같은 사이트로 읽히지 않는다.

---

## 2. 타이포 스케일

전부 `clamp()` 기반 유동 크기다. 뷰포트가 커지면 함께 커진다 — 디자인 컨셉 §16 의 "SCALE" 을 구현하는 수단이다.

| 토큰              | 값                              | 쓰는 곳                           |
| ----------------- | ------------------------------- | --------------------------------- |
| `--text-display`  | `clamp(2.75rem, 9vw, 8rem)`     | 홈 히어로 헤드라인 **한 곳뿐**    |
| `--text-headline` | `clamp(2rem, 5.5vw, 4.5rem)`    | 각 페이지 `h1`, 마무리 CTA        |
| `--text-title`    | `clamp(1.375rem, 2.5vw, 2rem)`  | 섹션 `h2`, 서비스 · 프로젝트 제목 |
| `--text-eyebrow`  | `0.75rem`                       | 섹션 번호 · 분류 라벨 (고정 크기) |
| 본문              | 브라우저 기본(1rem) · `text-lg` | 설명 문단                         |
| 보조              | `text-sm` · `text-[0.6875rem]`  | 목록 항목 · 메타 정보 · 출처 표기 |

**`--text-display` 는 히어로 전용이다.** 다른 곳에 쓰면 첫 화면의 위계가 무너진다.

### 서체

| 용도 | 스택                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 본문 | `--font-sans` — Pretendard → 시스템 한글 폰트 순 (debt-001: 웹폰트 미도입) |
| 라벨 | `--font-mono` — eyebrow · 수치 · 출처 표기처럼 **기계가 만든 값**에만      |

모노스페이스는 장식이 아니라 **"이건 사람이 쓴 문장이 아니라 값이다"** 라는 신호로 쓴다.

## 3. 제목 · 여백 규격

### 헤딩 구조

`SectionHeading` 하나만 쓴다. 직접 `<h1>`/`<h2>` 를 쓰지 않는다 — 크기와 간격이 갈라진다.

```tsx
<SectionHeading as="h1" eyebrow="About" title="..." body="..." />
```

| 요소    | 규격                                                                 |
| ------- | -------------------------------------------------------------------- |
| eyebrow | `--text-eyebrow` · mono · `tracking-[0.3em]` · 대문자 · `text-faint` |
| title   | `as="h1"` → `--text-headline` / `as="h2"` → `--text-title`           |
| 공통    | `leading-[1.05]` · `font-semibold` · `tracking-tight` · 대문자       |
| body    | `mt-6` · `max-w-2xl` · `text-muted` · `leading-relaxed`              |

- 제목은 **대문자 영문**, 본문은 한국어 — 디자인 컨셉 §6·§7 의 카피 스타일이다.
- 제목 폭은 `max-w-3xl` 로 묶는다. 한 줄이 길어지면 읽는 속도가 떨어진다.

### 페이지 첫 섹션

| 페이지 유형                                           | 규격                               |
| ----------------------------------------------------- | ---------------------------------- |
| **본문형** (Services · Projects · Technology · About) | `<Section wide className="pt-40">` |
| **단일 메시지형** (홈 히어로 · Contact)               | `fullHeight` (`min-h-svh`)         |

`pt-40` 은 고정 헤더(`h-20`) 아래로 제목이 충분히 내려오게 하는 값이다.

> **2026-08-13 정정**: About 첫 섹션만 `fullHeight` 를 쓰고 있어 제목과 다음 섹션(How We Work)
> 사이 간격이 다른 페이지와 달랐다. 본문형 규격으로 통일했다.
> **단일 메시지형은 예외가 아니라 다른 유형**이다 — 화면 하나에 한 문장만 두는 자리다.

### 섹션 리듬

| 항목        | 값                                           |
| ----------- | -------------------------------------------- |
| 세로 여백   | `--spacing-section` = `8rem`                 |
| 전체 화면형 | `py-24` + `min-h-svh`                        |
| 구분        | `border-t border-line` — **선 하나로만**     |
| 제목 → 내용 | `mt-12` (목록·표) / `mt-16` (그리드·큰 블록) |

카드나 박스로 구분하지 않는다(디자인 컨셉 §17). 구분은 **선과 여백**이 한다.

## 4. 목록 · 표

가장 많이 쓰는 형태는 **위아래 선으로만 나뉜 목록**이다.

```tsx
<ul className="border-t border-line">
  <li className="border-b border-line py-8">…</li>
</ul>
```

- 좌우 테두리를 두르지 않는다. 상자가 되는 순간 카드다.
- 격자형(기술 스택 · 워크플로)은 `gap-px` + `bg-line` 으로 **선을 배경으로** 만든다 —
  요소마다 테두리를 주면 선이 겹쳐 두꺼워진다.

---

## 5. 자간 · 대문자

| 상황              | 자간                |
| ----------------- | ------------------- |
| 큰 제목           | `tracking-tight`    |
| eyebrow · 라벨    | `tracking-[0.3em]`  |
| 버튼 · 내비게이션 | `tracking-[0.2em]`  |
| 소제목            | `tracking-[0.15em]` |

대문자는 자간을 넓히지 않으면 뭉쳐 보인다. **대문자를 쓰면 자간을 반드시 함께 준다.**
반대로 큰 제목은 자간을 좁혀야 덩어리로 읽힌다.

---

## 6. 색과 위계

| 토큰             | 용도                                   |
| ---------------- | -------------------------------------- |
| `--color-fg`     | 제목 · 본문 강조                       |
| `--color-muted`  | 설명 문단 · 목록 본문                  |
| `--color-faint`  | eyebrow · 메타 정보 · 비활성 상태      |
| `--color-accent` | 링크 hover · 상태 표시 **(본문 금지)** |

액센트를 본문 색으로 쓰지 않는다. 초록이 글에 들어오는 순간 배경의 초록과 경쟁한다.

---

## 7. 자체 점검

새 화면을 만들 때 확인한다.

- [ ] `h1` 이 페이지에 하나뿐인가
- [ ] 직접 `<h1>`/`<h2>` 를 쓰지 않고 `SectionHeading` 을 썼는가
- [ ] 임의의 픽셀 크기(`text-[52px]`)를 쓰지 않았는가
- [ ] 첫 섹션이 페이지 유형에 맞는 규격(`pt-40` 또는 `fullHeight`)인가
- [ ] 카드·둥근 모서리·그림자를 쓰지 않았는가
- [ ] 대문자에 자간을 줬는가
- [ ] 액센트 색을 본문에 쓰지 않았는가
