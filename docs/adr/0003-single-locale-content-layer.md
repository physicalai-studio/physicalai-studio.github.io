# ADR-0003 — 단일 로케일 + 콘텐츠 계층 분리

## Status

Accepted (2026-08-13)

## Context

디자인 컨셉은 짧은 영문 대문자 헤드라인 + 한국어 보조 문장이라는 카피 스타일을 요구한다. 초기 타깃 고객은 국내 산업·연구 고객이다. 한편 다국어를 나중에 도입하면 라우팅 구조 변경이 필요해 전면 재작업이 된다.

## Decision

- 라우트는 **단일 로케일**로 둔다. `[locale]` 세그먼트를 도입하지 않는다.
- 대신 **모든 문구를 `src/content/` 데이터 모듈에만 둔다.** 컴포넌트 내부 문자열 하드코딩을 금지한다.
- 콘텐츠는 zod 스키마(`src/content/schema.ts`)로 빌드 타임에 검증한다.

## Consequences

- 문구 교체가 데이터 파일 수정만으로 끝난다.
- 영문판이 필요해지면 `content` 모듈을 로케일별로 나누고 라우트 세그먼트를 추가하면 되며, **컴포넌트 수정은 발생하지 않는다.**
- 컴포넌트에 문자열을 직접 쓰면 이 이점이 무너지므로, 리뷰에서 이를 확인해야 한다(현재는 `⟦권고⟧` — 기계 검사 없음).
- 스키마 위반은 빌드를 실패시킨다.

## Rollback

가역. 단일 로케일에서 다국어로 가는 방향은 확장이지 되돌림이 아니다. 콘텐츠 계층 분리를 되돌릴 이유는 없다.
