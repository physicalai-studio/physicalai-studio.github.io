# 자산 맵 (Asset Map)

> **이 문서는 "어느 이미지가 어느 스크립트의 어떤 함수·파라미터에서 나왔는가"의 단일 대조표다.**
> 사이트에 보이는 모든 절차적 이미지는 여기 한 줄로 추적된다.
>
> 원본 사진이 **없다.** 스크립트와 파라미터가 곧 원본이므로, 이 표만 있으면 전부 재생성할 수 있다.
>
> 최종 갱신: 2026-08-15

## 3-1. 케이스 스터디 텍스처 (`gen-case-textures.py`)

`image/concept/` 의 탐색 이미지를 **크롭 · 회전 · 강한 블러 · 초록 램프**로 가공한 20종.
실제 캡처가 없는 케이스 스터디의 자리를 채운다(debt-008).

| 항목      | 값                                                               |
| --------- | ---------------------------------------------------------------- |
| 출력      | `public/media/case/case-01.webp` … `case-20.webp` (1600×900)     |
| 블러      | 반경 28~52px — 형상을 알아볼 수 없게 만드는 핵심 단계            |
| 대비      | 부동소수점 백분위 정규화(2~98%) + **최소 스트레치 폭 0.18**      |
| 밝기 하한 | 평균 0.055 — 이보다 어두우면 끌어올린다(목록에서 빈 칸처럼 보임) |
| 배정      | `caseTextureSlot(slug)` — 슬러그 해시로 결정적 선택              |

> **현재 게시된 케이스 중 이 풀을 쓰는 것은 없다.** 텍스처를 쓰던 2건(자세 제어 · 주행 스택)은
> 2026-08-13 에 각 케이스 전용 절차 이미지(`VORTEX`·`SEAM`)로 교체했다.
> 풀과 배정 함수는 **새 케이스가 생겼을 때의 폴백**으로 남긴다.

> `ImageOps.autocontrast` 를 쓰면 8비트 양자화 단차가 확대되어 밴딩이 생긴다.
> 부동소수점에서 직접 정규화하고 미세 디더를 더한다.

## 4. 탐색 자산 (`gen-concept.py`)

사이트에 **쓰이지 않는다.** 형태를 고르기 위한 후보다.

| 형태      | 뜻 (컨셉 §2)                     | 파일 규칙                           |
| --------- | -------------------------------- | ----------------------------------- |
| `ring`    | `RING` 을 구조물로 옮긴 변형     | `image/concept/ring-NNN-seedS.webp` |
| `burst`   | 파면 — 중심에서 퍼져 나가는 경계 | `burst-NNN-seedS.webp`              |
| `fractal` | 간섭 — 수렴/발산이 갈리는 경계   | `fractal-NNN-seedS.webp`            |

파일명에 시드가 들어가므로 마음에 드는 것을 그 시드로 언제든 정확히 재생성할 수 있다.

## 5. 재생성 절차

```bash
python3 scripts/gen-fields.py     # 배포 배경 4종 + 파비콘 2종 (덮어씀)
python3 scripts/build-media.py    # 사진 유래 자산 전부 (덮어씀)
python3 scripts/gen-concept.py --form burst --seed 41   # 탐색 자산 (새 번호로 추가)
npm run verify                    # 스키마·빌드 검증
```

**원본을 덮어쓰는 스크립트는 없다.** `image/` 의 사진과 `image/concept/` 의 탐색물은 그대로 남는다.

## 6. 새 배경을 추가할 때

1. **컨셉 문서 §2 대응표의 어느 줄인지 먼저 답한다.** 못 하면 만들지 않는다 (가이드 §21).
2. `gen-fields.py` 에 `build_*_field()` 를 쓰고 docstring 에 그 대응을 명시한다.
3. `main()` 의 `render(...)` 에 등록한다.
4. `src/content/media.ts` 에 슬롯을 추가한다 (`clearance: "self-produced"`).
5. 페이지에서 쓴다. 전체 배경이면 `PageBackdrop` 을, 섹션 배경이면 절대배치 래퍼를 쓴다.
   **`MediaSlot` 에 `absolute` 를 직접 넘기지 않는다** — 내부 `relative` 와 충돌한다.
6. **이 표에 한 줄 추가한다.**
